## 2. The 5-Stage Autonomous Development Loop

```
[1. PM Scope] ➔ [2. UI/UX Design & Tokens] ➔ [3. Architecture] ➔ [4. GSD Build] ➔ [5. QA & CodeRabbit Sign-off]
```

1. **PM Scope**: Define farmer persona requirements, edge cases, and language considerations.
2. **UI/UX Design**: Define design tokens (colors, typography, spacing, component states) before writing code.
3. **Architecture**: Model data schemas, API contracts, and offline fallbacks.
4. **GSD Rapid Build**: Implement modular components in rapid atomic steps with continuous verification.
5. **QA & CodeRabbit Sign-off**: Test functionality, audit security, and produce a CodeRabbit-style review card.

## 3. UI/UX Design System Standards (Krushi Drushti)

- **Color Palette**:
  - *Forest Emerald* (`#059669` / `#10b981`): Health, vitality, crops.
  - *Sunlit Amber / Harvest Gold* (`#f59e0b` / `#d97706`): Sunlight, ripeness, alerts.
  - *Deep Earth Dark Slate* (`#0f172a` / `#1e293b`): Premium contrast, readability.
  - *Soft Dew Off-White* (`#f8fafc`): Clean background and cards.
- **Farmer-First Usability**:
  - Minimum 48px touch targets for mobile thumb usability in outdoor fields.
  - High-contrast visual cues and icons for low-literacy or sunlight visibility.
  - Clear visual feedback for every AI scan and background sync action.
- **Aesthetic Excellence**:
  - Subtle backdrop glassmorphism (`backdrop-filter: blur(12px)`).
  - Smooth micro-interactions on cards, tabs, and image dropzones.
  - Informative status badges (e.g., Healthy, Infected, Action Required).
