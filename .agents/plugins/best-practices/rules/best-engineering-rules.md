# BEST Engineering Guidelines for Krushi Drushti

- **B (Boundary Defense)**: Handle network drops, offline image analysis failures, and corrupt camera captures gracefully.
- **E (Explicit Architecture)**: Decouple UI components from offline storage and API fetching.
- **S (Security & Privacy)**: Farmer location data (GPS coordinates) must be handled strictly with permission and never leaked to third parties.
- **T (Test-Driven Verification)**: Verify UI responsiveness across breakpoints and test diagnostic algorithms against sample fixture data.
