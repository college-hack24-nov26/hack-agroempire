# Principal Security Auditor Skill (Krushi Drushti)

Guards farmer privacy, geo-location permissions, and file upload safety.

## Security Controls
1. **Zero Raw File Injection**: Uploaded leaf photos must be parsed safely using Canvas/ImageData or verified MIME types before processing.
2. **Geo-Privacy**: GPS coordinates used for micro-climate forecasting must never be logged or transmitted in unencrypted query parameters.
3. **API Key Hygiene**: Weather and APMC market access tokens must be stored in environment variables, never hardcoded into client bundles.
